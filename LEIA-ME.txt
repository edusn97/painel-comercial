COMO SUBIR (3 passos, ~2 minutos)
=================================

1) Abra o repositorio:
   https://github.com/edusn97/painel-comercial

2) Clique em  Add file  ->  Upload files
   Abra ESTA pasta (_subir-no-github), selecione TUDO que esta dentro
   dela  (Ctrl+A)  e arraste para a area de upload do GitHub.
   Precisa aparecer na lista:  .github , config , Dashboard-template.html ,
   Puxar-Funil-PaperVines.ps1 , gerar-analise-historica.py
   Depois clique em  Commit changes.

   IMPORTANTE: arraste o CONTEUDO da pasta, nao a pasta inteira.
   Se subir a pasta _subir-no-github junto, o script fica no lugar
   errado e a analise nao gera (foi o que aconteceu antes).

3) Aba  Actions  ->  Painel Comercial  ->  Run workflow  ->  Run workflow

=========
